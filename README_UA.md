## Одна ризик-матриця + automode (нове у v8.1.9-p1)
Одна таблиця в CORE відповідає на "скільки процесу / хто затверджує / скільки
агентів": **LOW** (зробив → один доказ), **NORMAL** (короткий план → виконує без
затвердження → verifier), **HIGH** (план → моє затвердження → ревюер на кожен
зачеплений ризик), **DESTRUCTIVE/гроші/прод/секрети** (завжди явний OK, повний
pipeline). Сесійний перемикач **"automode on/off"** зсуває NORMAL→LOW;
DESTRUCTIVE не зсувається ніколи. Старі AUTONOMY A/B/C і execution lanes видалені —
було чотири політики, стала одна.

## Як працює (коротко)
- `/start` → агент-практик проводить анкету й пропонує команду під проєкт (тільки
  core активні; решта — список рекомендацій). Рівень автономії: дефолт **B**
  (фінал за тобою); **A** — ризик-тірний авто; **C** — стоп на кожному ворота.
- `/research <тема>` → дослідити поточний стан ПЕРЕД планом (свіже > навченого).
- Перевіряючі — за ризиком (скіл `orchestration`), паралельно й незалежно;
  головний `verifier` зводить і повертає на допрацювання (зворотний цикл).
- Гейт закриває задачу, не слово агента. Будь-який RED / без доказів / необоротне /
  BLOCKED-гейт → стоп і клич людину.

## Чесні застереження
- **Автоматичний ланцюг — так; автоматична довіра — ні.** Незалежність перевіряючих,
  зупинка на RED/без доказів, скінченний ланцюг і гейт як детермінований замок —
  саме це дає результат без самообману.
- **Межа «незалежності».** Усі перевіряючі — одна базова модель: вони корельовані,
  спільні сліпі плями лишаються. Незалежність ЗНИЖУЄ, але не усуває rubber-stamping.
  На Codex «послідовні проходи» ще слабші (ті самі ваги, той самий контекст).
- **Вартість моделей.** Reviewers за замовчуванням `opus` (час > токени). Якщо для
  конкретного проєкту токени дорожчі — даунгрейдь не-high-risk ролі на `sonnet`
  у їхніх файлах. Деталі в `team-proposal` → «Token economy».

  диск + шлях до транскрипту, не in-context-синтез — це сітка, що доповнює гігієну
  контексту, не замінює її.

  `/clear` нічого не губить; усередині задачі — `/compact`, не `/clear`.
