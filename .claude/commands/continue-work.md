# /continue-work — відновити активну задачу з handoff

Виконай skill `handoff`, **Режим 2 (Відновлення)** для `.claude/handoffs/current.md`:
читай лише при `Task status: ACTIVE`; звір git HEAD з зазначеним у handoff;
live-факти перевіряй живими командами (`.claude/rules/verify-external-state.md`);
підтверди ціль і наступну дію одним рядком — і виконуй розділ 7.

Це ЄДИНИЙ шлях відновлення задачі після `/clear` або на старті сесії —
без цієї команди активний handoff лише анонсується, але не читається.
(Після авто-компакції відновлення відбувається автоматично, ця команда
для цього не потрібна.)
