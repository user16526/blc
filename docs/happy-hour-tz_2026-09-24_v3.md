# ТЗ: Happy Hour — старт (v3, 24.09) — лише налаштування адмінки
Замінює `docs/happy-hour-tz_2026-09-23_2200_v2.md` (зміна: колесо з 3 кейсів замість 1 приза).
Основа: скрін адмінки 23.09 (Create Happy Hour planner) + опис менеджера + відповіді Івана.

1/ Експеримент 3 тижні: **старт чт 24.09 → останній день ср 14.10**, вранці 15.10 на обох
   планерах Is active = off. Якщо старт зсувається — рахуємо 21 день від фактичного старту.

2/ Час — UTC.

3/ Групи (вже є): H0 — без Happy Hour (контроль) · H1 — ранковий планер · H2 — вечірній.

4/ Два планери, налаштування однакові, крім часу:

| поле | H1 (ранок) | H2 (вечір) |
|---|---|---|
| Cron expression | `0 2 * * *` | `0 18 * * *` |
| Duration (min) | 180 (02:00–05:00) | **300 (18:00–23:00)** |
| Is cyclic | on | on |
| Is active | on | on |

   Вечір — 5 годин: охоплення ~32 % клієнтів за 3 тижні замість ~20 % при 3 годинах.
   Якщо після збереження H2 перестає показуватись своїй групі — повернути 180.

5/ Призи (однакові в обох планерах) — 3 слоти, приз випадає рівноймовірно (weight ігнорується):
   - Prize #1: Case, Case ID **643** (nuke-case, $2.12)
   - Prize #2: Case, Case ID **3** (ak-47, $4.99)
   - Prize #3: Case, Case ID **700** (felix-case, $7.00)
   Середня вартість приза ~$4.70 (собівартість ~$3.30 при маржі 30 %). Колесо з різними
   призами читається як гра; усі три — нагорода одразу, без умов використання.
   Бонус на депозит, коїни і квитки не ставимо: бонус спрацьовує лише на НАСТУПНИЙ депозит
   і лише якщо вигідніший за стандартний; вартість коїнів/квитків ми не можемо порахувати.

6/ Умови (обидва планери, 2 штуки):
   - Condition #1: **Make deposit**, Deposit (cents) = **500** (від $5);
   - Condition #2: **Not participated 24h**.
   Open case і No condition не додаємо.

7/ Під час тесту нічого не міняємо: ні призи, ні час, ні умови. Акцію «депозит ≥ $25 →
   star-case» (#104) продовжити до 15.10, щоб вона йшла весь тест.

8/ Після 3 тижнів порівнюємо (рахую я з бази):
   8.1/ **основне: частка клієнтів із депозитом, H2 проти H0** — серед тих, хто був на сайті
        о 18:00–23:00 хоча б раз, з дня першого такого візиту;
   8.2/ депозитів і суми депозитів на клієнта, H2 проти H0;
   8.3/ H1 проти H0 — дивимось, але вранці мало людей, результату, найімовірніше, не буде;
   8.4/ витрати: видані кейси × собівартість по кожній групі.
   Тест помітить приріст від ~27 %; менший ефект = «не видно», а не «не працює».

Орієнтовні витрати: ~15 переможців на день у H2 × ~$3.30 ≈ $50/день, ~$1–1.2k за 3 тижні
разом з H1 (оцінка за депозитами 18–23 UTC за останні 14 днів).

Питання, на яке відповідає тест: **чи дає Happy Hour більше депозиторів, ніж його відсутність.**
