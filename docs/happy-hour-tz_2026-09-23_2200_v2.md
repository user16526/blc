# ТЗ: Happy Hour — експеримент (v2, 23.09) — лише те, що налаштовується в адмінці
Замінює `docs/happy-hour-tz_2026-09-23_0300_v1.md` (тестував бонус проти кейсу в одному вікні —
в адмінці так не можна: групи прив'язані до вікон, а не до призів). Шериф: 5 знахідок, враховано.

1/ Запускаємо експеримент на 3 тижні: **чт 24.09 → ср 14.10**, вимикаємо вранці 15.10
   (Is active = off на обох планерах). Напиши тут, коли стартуємо!

2/ Час — UTC.

3/ Групи — як уже зроблено: кожен клієнт (за хешем client_id) на всі 3 тижні в одній групі:
   - **H0 (~1/3)** — Happy Hour не бачать (контроль).
   - **H1 (~1/3)** — Happy Hour вранці: планер `0 2 * * *`, **Duration 180** (02:00–05:00).
   - **H2 (~1/3)** — Happy Hour ввечері: планер `0 18 * * *`, **Duration 300** (18:00–23:00).
   Обидва планери: Is cyclic = on, Is active = on.
   Ввечері 5 годин замість 3: старт той самий (18:00), а охоплення ~32 % замість 20 % —
   це головне, від чого залежить, чи тест щось покаже.

4/ **Приз — один і той самий в обох планерах** (порівнюємо вікно з контролем, приз не змінюємо):
   - Prize type **Case**, Case ID = **3 (ak-47, $4.99)**, 1 шт.
   Альтернатива, якщо хочете бонус: Deposit bonus, min = max = **50 %**, депозит від $5 до $200,
   термін дії **24 години**. Бонус спрацьовує на НАСТУПНИЙ депозит і тільки якщо він вигідніший
   за стандартний (20–25 % на перший, 6–10 % на наступні) — кейс дає нагороду одразу, тому простіший.

5/ Умови (обидва планери):
   - **Make deposit**, Deposit (cents) = **500** (від $5);
   - **Not participated 24h**.

6/ Для пост-аналітики треба пам'ятати:
   6.1/ хто з кожної групи, **включно з H0**, був на сайті у своєму вікні — дата першого разу,
        нові / старі (для H0 — ті самі години, що в H2);
   6.2/ **основна метрика: частка клієнтів із депозитом за 3 тижні, H2 проти H0.**
        Рахуємо всіх, хто хоч раз був у вікні, з дня першого візиту, і не викидаємо нікого потім.
        Тест бачить різницю від **~27 %**; менший ефект = «не видно», а не «не працює».
   6.3/ H1 проти H0 — теж дивимось, але вранці лише ~7 % клієнтів, тож результату майже
        напевно не буде (це відомо заздалегідь);
   6.4/ витрати: скільки кейсів видано по кожній групі × собівартість (~$3.49 за ak-47) —
        це контроль витрат, не критерій переможця.

7/ Під час тесту умови не міняємо: акцію «депозит ≥ $25 → star-case» (#104, зараз до 08.10)
   продовжити до 15.10.

Питання, на яке відповідає тест: **чи дає Happy Hour з кейсом більше депозиторів, ніж без нього.**
Якщо так — наступним тестом порівнюємо призи (кейс проти бонусу); для цього розробці
треба буде дати можливість різним групам різні призи в одному вікні.
