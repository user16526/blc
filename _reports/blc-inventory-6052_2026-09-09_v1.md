## SQL used
```sql
-- summary
SELECT count(DISTINCT steam_item_hash) AS distinct_skins, count(*) AS items,
       sum(buyout_price) AS total_buyout,
       count(*) FILTER (WHERE last_market_check_at IS NULL) AS never_price_checked
FROM public.client_items
WHERE client_id = 6052 AND _ab_cdc_deleted_at IS NULL
  AND sold_at IS NULL AND status = 1 AND is_virtual_nft_item = false;
-- 430 | 551 | 211670 | 551

-- per-skin list (source of the table above)
SELECT steam_item_hash AS skin, count(*) AS qty,
       max(buyout_price) AS unit_cents, sum(buyout_price) AS line_cents
FROM public.client_items
WHERE client_id = 6052 AND _ab_cdc_deleted_at IS NULL
  AND sold_at IS NULL AND status = 1 AND is_virtual_nft_item = false
GROUP BY steam_item_hash
ORDER BY line_cents DESC, skin;
```

## Caveats
- Prices are the site's stored buyout values, never market-refreshed (see the ⚠ note).
  Treat them as "what the site pays", not "current Steam market price".
- `unit $` is `max(buyout_price)` within a line; items of the same name can differ
  slightly in stored price, so `line $` is the true sum, not always `qty × unit`.
- `status` semantics (1 = sellable, 8/9 = pending/locked, 4/11 = disposed) are inferred
  from the data, not from app code.
- CDC replica — accurate as of last sync. The "Sell all" total matched to the cent.
- Client 6052 is an unflagged internal/QA account
  (see `_reports/blc-data_2026-09-09_0041_v1.md`). This inventory is not
  representative of a real player.
