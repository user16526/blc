## Caveats
- Deposits/FTD include the unflagged internal accounts (as in earlier reports). Registrations use the real-user predicate.
- Status 3 = not paid; the replica does not show whether that is a bank decline, 3DS failure or an abandoned checkout.
- `deposits.country` meaning (IP vs card vs profile) is not verified.
- Payment-system names from `public_fwd.payment_systems` (row updated_at 2023 — names only).
- GA4 "key events" = all key events of the property; composition not re-audited.
- Before/after, not controlled: seasonality and whale behaviour are not separated.

## SQL
```sql
-- daily funnel (run for 07-15→08-31 and 09-01→09-28, same shape)
with days as (select g::timestamp as d from generate_series('2026-09-01'::timestamp,'2026-09-28'::timestamp,'1 day'::interval) g),
fd as (select client_id, deposit_id, created_at from analytics.first_deposit where created_at >= '2026-09-01' and created_at < '2026-09-30'),
reg as (select date_trunc('day',c.created) as d, count(*) as n,
   count(f.client_id) filter (where f.created_at < c.created + interval '1 day') as c1,
   count(f.client_id) filter (where f.created_at < c.created + interval '7 day') as c7
  from public.clients c left join fd f on f.client_id=c.id
  where c.created >= '2026-09-01' and c.created < '2026-09-29' and (c.flags&1)=0 and (c.flags&64)=0
    and c.deleted_at is null and c._ab_cdc_deleted_at is null group by 1),
pd as (select date_trunc('day',p.paid_at) as d, p.client_id, p.amount, case when f.deposit_id is null then 0 else 1 end as is_ftd
  from public.deposits p left join fd f on f.deposit_id=p.id
  where p.paid_at >= '2026-09-01' and p.paid_at < '2026-09-29' and p._ab_cdc_deleted_at is null),
dep as (select d, count(*) filter (where is_ftd=1) as ftd, round(avg(amount) filter (where is_ftd=1)/100.0,1) as ftd_avg,
   round(sum(amount) filter (where is_ftd=1)/100.0) as ftd_gmv, count(*) filter (where is_ftd=0) as rep_n,
   count(distinct client_id) filter (where is_ftd=0) as rep_payers, round(avg(amount) filter (where is_ftd=0)/100.0,1) as rep_avg,
   round(sum(amount) filter (where is_ftd=0)/100.0) as rep_gmv, count(distinct client_id) as payers, round(sum(amount)/100.0) as gmv
  from pd group by 1),
att as (select date_trunc('day',created) as d, count(distinct client_id) as try_c,
   count(distinct client_id) filter (where paid_at is not null) as ok_c
  from public.deposits where created >= '2026-09-01' and created < '2026-09-29' and _ab_cdc_deleted_at is null group by 1)
select to_char(days.d,'MM-DD') as dd, reg.n as reg, reg.c1, reg.c7, dep.ftd, dep.ftd_avg, dep.ftd_gmv, dep.rep_n, dep.rep_payers,
  dep.rep_avg, dep.rep_gmv, dep.payers, dep.gmv, att.try_c, att.ok_c
from days left join reg on reg.d=days.d left join dep on dep.d=days.d left join att on att.d=days.d order by 1 limit 50;

-- aligned DAU + event XP earners; day n = start date + n
with ev as (select 'prev' as k, 'ddcce517-e46a-47b9-adf7-8e2c9e09338f'::uuid as id, '2026-07-22'::timestamp as s
   union all select 'new', 'ae9a967d-a97c-4996-8e8c-60eef48c57e7'::uuid, '2026-09-08'::timestamp),
```
