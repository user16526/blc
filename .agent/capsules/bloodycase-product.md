# Capsule: BloodyCase — product & domain
Last updated: 2026-09-01
Owner lens: Product / Marketing (gaming-product-owner)

## Current facts
- BloodyCase is an online case-opening platform. Game mix: CS2 ~90%, RUST ~8%,
  Dota 2 ~2%. Users buy or earn cases and receive randomized weapon skins that
  carry real monetary value.
- Game modes: standard case opening, Case Battles, Sniper Battle, Skin Upgrader,
  Trade-Up Contracts.
- Monetization: deposits (minimum $5), a **25%** first-deposit bonus, daily giveaways.
- Registration/auth providers: Steam, Google, Discord, Facebook, Twitch.
- Analytics we actually have access to: Google Analytics 4 (traffic, conversion,
  retention) and Microsoft Clarity (session recordings, heatmaps).
- Product stack, for context only: Angular frontend, Go backend.

## Non-negotiables
- Our scope is product, marketing and UI/UX. We do NOT write or modify BloodyCase
  application code — the dev team owns all technical implementation.
- Out of scope entirely: payment providers, Steam API, the Provably Fair verification
  backend, game integrations.
- Never publish a first-deposit bonus figure other than 25%.

## Active risks
- [open] Skin-gambling adjacency: ad platforms and app stores restrict this category.
  Any paid-acquisition plan must check channel policy before spend.

- BloodyCase, case opening, case battles, sniper battle, skin upgrader, trade-up,
  CS2, RUST, Dota 2, deposit bonus, giveaway, GA4, Clarity, retention, conversion
